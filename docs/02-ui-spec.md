# 02. UI/UX 상세 명세

## 1. 참고 이미지 분석

첨부된 이미지는 다음 특징을 가진다.

- 흰색 배경과 넓은 여백
- 화면 상단의 얇은 navigation
- 중앙 콘텐츠 폭이 넓지만 실제 텍스트는 여유 있게 배치
- 왼쪽에 큰 제목, 오른쪽에 큰 비주얼 카드
- 제목의 일부만 핑크로 강조
- 둥근 pill 형태의 작은 버튼
- 큰 둥근 입력/검색 영역
- 아래쪽에 카드들이 가로로 배치된 구조
- 짙은 텍스트와 밝은 보조 텍스트의 대비

감성 분석 제품에서는 원본의 카드 갤러리를 그대로 복사하지 않고, 분석 결과를 보여주는 카드 구조로 변환한다.

## 3. 색상 방향

정확한 색상값은 구현 과정에서 디자인 토큰으로 관리한다.

- 기본 배경: white
- 기본 텍스트: 거의 검정에 가까운 navy
- 강조색: pink
- 카드 배경: 아주 옅은 gray
- 테두리: 연한 gray
- 성공/긍정: 별도 보조색을 사용할 수 있지만 색상만으로 의미를 전달하지 않는다.

참고 이미지의 핑크 강조를 제품의 핵심 CTA와 감성 강조에 활용한다.

---

## 4. Typography

- 제목: 크고 굵게
- 본문: 읽기 편한 중간 크기
- 결과 숫자: 크고 굵게
- 보조 설명: 작은 크기와 낮은 대비
- 한국어가 깨지지 않는 시스템 폰트 또는 웹폰트를 사용한다.

---

## 5. 입력 영역

### 기본 상태

placeholder:
`오늘의 문장이나 리뷰를 입력해 보세요.`

버튼:
`감성 분석하기`

### 로딩 상태

버튼:
`분석 중...`

버튼은 비활성화한다.

### 성공 상태

결과 카드가 입력 영역 아래에 나타난다.

### 오류 상태

입력값 문제라면 입력 영역 아래에 즉시 메시지를 표시한다.
서버/AI 문제라면 결과 영역에 재시도 가능한 메시지를 표시한다.

---

## 6. 결과 카드

필수 요소:

1. `감성 분석 결과` 라벨
2. `긍정 / 부정 / 중립` 배지
3. `신뢰도 NN%`
4. `분석 이유`
5. 선택적으로 짧은 안내 문구:
   `신뢰도는 AI 모델의 판단 확신 수준이며 실제 정답 확률을 의미하지 않습니다.`

---

## 7. 반응형

### Desktop

- hero 2열
- 최대 콘텐츠 폭을 제한
- 입력창은 넓게
- 결과 카드도 중앙 정렬

### Mobile

- hero를 1열로 변경
- 오른쪽 비주얼 카드는 결과 미리보기 카드로 축소
- 버튼은 충분한 터치 영역 확보
- 제목 크기 축소
- 가로 스크롤을 유발하는 고정 폭을 사용하지 않는다.

---

## 8. 접근성

- input/textarea에 label 제공
- 버튼은 명확한 동작 이름 사용
- 결과 영역에 `aria-live` 적용
- 포커스 표시 유지
- 감성 상태를 텍스트로도 표시
